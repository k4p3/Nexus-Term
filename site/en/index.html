NexusTerm

Modern, lightweight, zero-knowledge SSH/SFTP manager and terminal. A 100% free alternative to Termius, Tabby or MobaXterm.

DownloadHow to use it
  • GPLv3
  • Linux · Windows · macOS
  • Tauri v2 + Rust

Your terminal, with superpowers

Every command is a block that shows whether it succeeded (✓) or failed (✗) and how long it took. Copy its output, re-run it, or search only inside it.

What is inside

Everything you need to manage servers, in a single application.

🔐

Zero-knowledge vault

Credentials and SSH keys are encrypted per record with AES-256-GCM. The master password is stretched with Argon2id and is never written to disk; keys are wiped from memory on lock.

🖥️

SSH, SFTP and telemetry

One authenticated SSH connection serves the interactive shell, the SFTP explorer with a transfer queue, and a live CPU/RAM/network bar.

🪟

Split panes and tabs

Split any tab horizontally or vertically, dock tabs into panes, and broadcast your keystrokes to several servers at once.

🧭

Tunnels and jump hosts

Local (-L), remote (-R) and dynamic SOCKS5 (-D) port forwarding, and chained bastion hosts.

🖱️

RDP and VNC

Open graphical desktops as tabs next to your terminals.

⚡

A smarter terminal

Command blocks with ✓/✗ and duration, per-host encrypted history, Instant Replay, Quick Select, safe paste and smart links.

📋

Snippets

A library of parameterised commands with {{placeholders}}, plus a catalogue of community snippets for Docker, systemd and networking.

🎨

Themes and languages

Tokyo Night, One Dark, Dracula, Catppuccin, Nord and KDE Breeze Dark, with English and Spanish built in.

🪶

Lightweight

Built with Tauri v2 and Rust: no Electron, a small memory footprint and a WebGL-accelerated terminal.

Encrypted per-host history

Press Ctrl+Shift+H to search the commands you already ran on that server, together with your snippets. It is stored encrypted in the vault and never records commands that look like secrets.

There is also Instant Replay (Ctrl+Shift+Y) to recover output wiped by a clear, and tab restore when you reopen the app.

Security: zero knowledge

  • Master password stretched with Argon2id (64 MiB, 3 iterations, 4 threads); never stored on disk.
  • Every record is encrypted with AES-256-GCM and a unique IV.
  • Change the master password without re-encrypting all your servers.
  • Keys are wiped from memory when the vault locks.
  • No accounts and no cloud service: your data stays on your machine.
  • NexusTerm collects no usage data and contacts no service other than the servers you connect to. No analytics, no crash reporting and no update checks; the code is open and an automated test in the repository guards this.

Install

Download the installer for your system from the releases page: AppImage, .deb and .rpm for Linux, .msi/.exe for Windows and .dmg for macOS.

Go to releases

On Linux (AppImage)

chmod +x nexus-term_*_amd64.AppImage
./nexus-term_*_amd64.AppImage

From source

git clone https://github.com/k4p3/Nexus-Term.git
cd Nexus-Term
pnpm install
pnpm tauri dev

Requires Node.js 20+, pnpm and stable Rust; on Linux you also need the WebKitGTK dependencies (see the README).
