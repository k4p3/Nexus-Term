NexusTerm

Gestor SSH/SFTP y terminal moderno, ligero y de conocimiento cero. Una alternativa 100% libre a Termius, Tabby o MobaXterm.

DescargarCómo se usa
  • GPLv3
  • Linux · Windows · macOS
  • Tauri v2 + Rust

Tu terminal, con superpoderes

Cada comando es un bloque que muestra si salió bien (✓) o mal (✗) y cuánto tardó. Puedes copiar su salida, repetirlo o buscar solo dentro de él.

Qué incluye

Todo lo que necesitas para gestionar servidores, sin salir de una sola aplicación.

🔐

Bóveda de conocimiento cero

Las credenciales y llaves SSH se cifran por registro con AES-256-GCM. La contraseña maestra se deriva con Argon2id, nunca se escribe en disco y las llaves se borran de la memoria al bloquear.

🖥️

SSH, SFTP y telemetría

Una única conexión SSH autenticada sirve la terminal interactiva, el explorador SFTP con cola de transferencias y una barra de CPU/RAM/red en vivo.

🪟

Paneles divididos y pestañas

Divide cualquier pestaña en horizontal o vertical, acopla pestañas en paneles y envía tus teclas a varios servidores a la vez (Broadcast).

🧭

Túneles y jump hosts

Reenvío de puertos local (-L), remoto (-R) y dinámico SOCKS5 (-D), y bastiones encadenados.

🖱️

RDP y VNC

Abre escritorios gráficos como pestañas junto a tus terminales.

⚡

Una terminal más inteligente

Bloques de comandos con ✓/✗ y duración, historial cifrado por host, Instant Replay, Quick Select, pegado seguro y enlaces inteligentes.

📋

Snippets

Biblioteca de comandos con parámetros {{placeholders}} y un catálogo comunitario para Docker, systemd y red.

🎨

Temas e idiomas

Tokyo Night, One Dark, Dracula, Catppuccin, Nord y KDE Breeze Dark, con inglés y español incluidos.

🪶

Ligera

Construida con Tauri v2 y Rust: sin Electron, poco consumo de memoria y terminal acelerada con WebGL.

Historial por host, cifrado

Pulsa Ctrl+Shift+H para buscar entre los comandos que ya ejecutaste en ese servidor, junto a tus snippets. Se guarda cifrado en la bóveda y nunca registra comandos con aspecto de secreto.

También tienes Instant Replay (Ctrl+Shift+Y) para recuperar la salida que borró un clear, y restauración de pestañas al reabrir la aplicación.

Seguridad: conocimiento cero

  • Contraseña maestra con Argon2id (64 MiB, 3 iteraciones, 4 hilos); nunca se guarda en disco.
  • Cada registro se cifra con AES-256-GCM y un IV único.
  • Puedes cambiar la contraseña maestra sin recifrar todos tus servidores.
  • Las llaves se borran de la memoria al bloquear la bóveda.
  • Sin cuentas ni servicios en la nube: tus datos se quedan en tu equipo.

Instalación

Descarga el instalador para tu sistema desde la página de versiones: AppImage, .deb y .rpm para Linux, .msi/.exe para Windows y .dmg para macOS.

Ir a las versiones

En Linux (AppImage)

chmod +x nexus-term_*_amd64.AppImage
./nexus-term_*_amd64.AppImage

Desde el código fuente

git clone https://github.com/k4p3/Nexus-Term.git
cd Nexus-Term
pnpm install
pnpm tauri dev

Requiere Node.js 20+, pnpm y Rust estable; en Linux, además, las dependencias de WebKitGTK (consulta el README).
